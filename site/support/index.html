Frequently asked questions

How do I install FullyQualified?

Run it with Docker: clone the repository and run docker compose up, then open http://localhost:8080 and create the first account. Without Docker you need .NET 10 and a Postgres database; the README has the command. Database migrations are applied automatically when the app starts.

I lost my passkey. How do I get back in?

Ask an administrator of your organization to open the Users page and choose Reset passkey next to your name. You get a single-use link, valid for 24 hours, to set up a new passkey; doing so removes your old passkeys. If you are the only administrator, see the next question.

I am the only administrator and I lost my passkey.

Whoever runs the server can create a recovery link from the command line. With Docker: docker compose exec app dotnet FullyQualified.Web.dll recover alice@example.com --url https://fq.example.com. Use your email address or your name. The link works once, for 24 hours, and replaces your old passkeys.

Can I sign in with a password?

No. Accounts use passkeys, so there are no passwords to leak, reuse or reset. Add a passkey for each device you use, and keep at least two. Single sign-on through OpenID Connect is available if your organization runs an identity provider.

How do I invite colleagues, and what do the roles mean?

Administrators open the Users page, enter an email address (optional) and choose a role. A viewer reads results and reports, a member also adds and removes assets and starts scans, and an admin also manages people and alarms. The invitation is a single-use link that is valid for 7 days, and it is emailed when the server has an SMTP host configured.

How do I set up single sign-on?

Register FullyQualified as an application in your identity provider with the redirect URI https://your-host/auth/sso/signin-oidc, then set Sso:Authority, Sso:ClientId and Sso:ClientSecret on the server. Set Sso:AllowedDomains to the email domains that may sign in. People still need an invitation, unless you enable Sso:AutoProvision. The first account is always created with a passkey.

How do I get alarms in Slack, PagerDuty or email?

Open the Alarms page as an administrator. Paste a Slack incoming webhook or a generic webhook URL (for PagerDuty or Opsgenie), add email recipients, choose the lowest status that should raise an alarm, and press Send a test alarm. Email also needs an SMTP host on the server. Every delivery attempt, including failures, is listed on the Log page.

Why did I not get an alarm?

Check that alarms are enabled, that the minimum status is not higher than the problem, and that a channel is configured. A first result is only reported when it is worse than OK. Then open the Log page: it shows each check result and whether the alarm was delivered or failed, and why.

What is a tenant?

A tenant is one organization: its users, domains, results and alarm settings. Tenants cannot see each other's data. The first tenant ever created becomes the management tenant, and only its administrators can see all tenants, create new ones and help users in other tenants. A self-hosted installation for one company simply has one tenant.

How often are my domains scanned?

By default every six hours, and a failed check is retried after fifteen minutes. The interval is a server setting (Scanning:IntervalHours). You can also start a scan from an asset's page if you are a member or admin.

Why does a certificate say Manual (likely)?

FullyQualified guesses how a certificate is renewed: certificates from ACME authorities, or with a very short lifetime, are almost always automated, the rest are marked manual. It is a hint to help you find certificates that need a person, not a fact about your setup.

Can it check internal hostnames?

A self-hosted installation can, as long as the server can reach them. The planned hosted version cannot reach private networks, so it only checks public endpoints. Run your own installation for internal systems.

Does FullyQualified send my data anywhere?

It sends nothing to the project. To find certificates it asks the Certificate Transparency log search at crt.sh about your domain names, and it connects to the endpoints and DNS servers you tell it to check. Alarms go only to the channels you configure.

How do I upgrade?

Pull the new version and restart the container. Migrations are applied when the app starts, so back up the Postgres database first, as you would for any upgrade.
