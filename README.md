# FullyQualified

Every domain, fully qualified: certificates, DNS & NIS2 compliance.

FullyQualified is an open-source tool that monitors certificates and DNS records for domains. A paid hosted version is planned for teams that do not want to self-host.

Status: early setup. See [docs/PLAN.md](docs/PLAN.md) for the product plan and architecture.
